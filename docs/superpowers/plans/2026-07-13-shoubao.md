# 首爆系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付不含真实物品清单的聆风/LFM2 首爆拾取脚本框架。

**Architecture:** `QFunction-0_追加片段.txt` 提供拾取入口，`首爆处理.txt` 负责读取配置、判定状态、发放奖励、持久化和表现效果；配置和历史记录完全独立于参考端。`验证首爆系统.py` 只做离线静态与行为模拟。

**Tech Stack:** LFM2/Mir 脚本 TXT、Python 标准库 unittest、PowerShell。

## Global Constraints

- 不写入任何服务器。
- 不复制两个参考端的真实物品清单、玩家名或历史领取记录。
- 首爆按首次拾取判定，全服单件物品一次，跨 M2 重启保留。
- 成功必须触发奖励、屏幕震动、全屏公告和弹窗。
- 未知奖励类型必须阻止发放并保持未领取状态。
