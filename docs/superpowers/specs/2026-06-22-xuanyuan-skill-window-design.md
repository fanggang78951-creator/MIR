# 玄渊技能窗口黑金底板设计

## 目标

将当前透明的 `DStateWin` 技能窗口改为完整、不透明的黑金底板，同时保留截图中的六行技能结构、升级按钮和分页操作。

## 目标控件

- 主窗口：`DStateWin`
- 当前尺寸：`232 x 362`
- 当前坐标：左 `692`，上 `10`
- 当前背景：`Prguse_wil / 1906`
- 问题：当前资源仅形成局部边条，六条技能信息缺少完整底色。

## 视觉方案

- 采用完整黑金框体，底色全不透明。
- 外框使用暗铜金属雕花，风格与玄渊背包一致。
- 标题区使用“玄渊技能”，但不把功能文字烘焙进技能行。
- 中央保留干净深黑内容区，供原生技能图标、名称、经验、等级和升级按钮覆盖。
- 左侧“一、二、三、四、五、六”与六条技能逐行对齐：共同起点、共同中心线、共同间距。
- 底部分页区域保留，不烘焙可点击功能。

## 对齐规格

- 六条技能起始 Y：`48`
- 单行高度：`43`
- 行间距：`5`
- 左侧序号与对应技能行垂直居中。
- 最终坐标以编辑器现有控件实际边界为基准，小范围微调不改变控件层级。

## 施工策略

1. 制作 `232 x 362`、24 位 BMP 黑金底板和 PNG 预览。
2. 备份 `D:\素材文件夹\全新聆风\LFM2[20260530]\登录器\NewopUI.Pak` 与同目录 `NewUI\Mir.ui`。
3. 仅使用上述登录器目录 `NewopUI.Pak` 的空闲图片序号，不覆盖 `Prguse_wil / 1906`。
4. 在主界面编辑器中仅修改 `DStateWin` 的背景资源绑定。
5. 调整左侧六个序号控件的 Y 坐标，使其对应六条技能。
6. 保存界面文件，重新生成登录器，关闭旧客户端后测试。

## 不得修改

- 不修改技能名称、技能数据、技能经验、等级和升级条件。
- 不修改升级按钮、上下页按钮和任何点击路由。
- 不修改攻击、暴击、爆率、神力、切割、洗练、伤害等属性系统。
- 不整体替换 `Mir.ui`。
- 不优化 PAK。
- 不修改背包、首饰盒、生肖及其他人物界面。

## 验收标准

- 游戏内技能窗口有稳定、完整、不透明的黑金底板。
- 六条技能及左侧“一至六”逐行对齐。
- 技能图标、名称、经验、等级、升级按钮和翻页功能保持正常。
- 窗口无错位、遮挡、穿透或多余点击区域。
