# 十大陆第一批非战斗结构收口规格

## 目标

在不填写怪物、装备、称号、命格、处决等战斗真值，也不填写最终金币／元宝金额和真实 `1/x` 的前提下，完成转生材料、产出、消耗、回收、NPC配方一致性、BOSS称号卷来源和编码待办的结构闭环。

## 当前有效规则

1. “小卢恩”“大卢恩”是背包实物材料；“XXX的大卢恩”是追梦神器。所有数据库、脚本和表格均按物品全名与唯一编码严格区分。
2. 小卢恩、大卢恩在全服所有大陆均可掉落；旧“小怪只掉小卢恩、BOSS只掉大卢恩”失效，但可保留小怪偏小卢恩、BOSS偏大卢恩的权重方向。
3. 1—5转只使用小卢恩；6—10转只使用大卢恩。玩家达到10转后，小卢恩与大卢恩余量均可通过现有回收脚本换取货币。
4. 11—15转、16—20转各使用一种新的独立转生材料。四种转生材料只参与转生，不参与装备、生肖、称号等其他配方；玩家完成对应阶段后，多余材料可回收货币。
5. 转生NPC仍为利耶尼亚海域、盖利德、巨人山顶、王城罗德尔四处，每处5级，共20转。转生结构为“对应阶段专用材料＋金币／元宝”；币种交叉使用，最终数量与金额后续统一计算。币种方向按每5级一组：1—5为“金币、金币、金币＋元宝、元宝、金币＋元宝”；6—10为“元宝、金币＋元宝、金币、金币＋元宝、金币＋元宝”；11—15重复1—5；16—20重复6—10。
6. 第一、第二大陆不新增额外“大陆收藏材料”；删除此前误建的两个占位资源和关系，但保留C1、C2专属装备逐件图鉴。C3—C10已测试的八件大陆收藏材料继续保留。
7. C3—C10大陆收藏材料的 `Items Looks 7218—7225` 必须以实库回读为权威补回源表，不得重新编号。
8. C10称号 `[称号]艾尔登之王` 的材料统一为“失温熔炉楔”，NPC表与产消总账必须一致。
9. 所有合成后的穿戴物不可回收。
10. 未来BOSS可掉落称号卷；称号卷通常由BOSS掉落，每个守关BOSS均配置一张独立称号卷。称号卷不占装备位并参与乘区；名称、来源和结构本批确定，战斗属性与真实掉率后算。
11. 攻速突破是极高价值稀有属性，后续稀疏分配到命格、稀有武器、合成装备、时装武器及少量成就称号；本批只登记投放候选，不填数值。
12. 所有金币、元宝消耗及物品回收价由统一经济模型计算。`GAMEGOLD` 按元宝理解，禁止误标成金刚石；真实金额在击杀效率、人物爆率、鞭尸、掉率和战斗快照联算后填写。
13. 地图、界面、赞助地图不在本批施工范围；用户最终手动导入。
14. 现有怪物、装备成品表不得在本批修改。

## 本批交付

- 十大陆产出消耗闭环总账V1.2。
- 十大陆NPC与配方总账V1.1。
- 更新后的六份项目档案。
- BOSS称号卷来源表及编码／实库回读清单。
- 构建校验、公式错误扫描、视觉预览和确认归档。

- 所有装备、称号卷、命格、图鉴、转生等战斗属性。
- 攻速突破的具体装备与数值分配。
