# 《艾尔登法环》十大陆联合重做：Codex执行与接续说明

当前版本：`EL-C01-V1-20260820`

本目录已完成第一大陆“漂流群岛”的第一版实际设计数据，尚未部署。地图大小不参与任何检查，也不得成为执行阻断项。

## 一、先读哪些文件

1. `00_十大陆全局设计总账.xlsx`：确认十大陆顺序、跨大陆数值母线和当前任务指针。
2. `C01_漂流群岛/01_第一大陆数值与掉落校准表.xlsx`：核对36怪、38件装备、掉率、称号和NPC奖励闭环。
3. `C01_漂流群岛/20_怪物批量生成_漂流群岛重做.xlsx`：玄渊怪物批量生成输入。
4. `C01_漂流群岛/09_装备批量生成_漂流群岛专属重做.xlsx`：玄渊装备批量生成输入，严格按最新67列读取。
5. `C01_漂流群岛/怪物爆率/MonItems_GBK/`：服务器用GB18030文件；UTF8目录只用于阅读和比对。
6. `C01_漂流群岛/NPC设计/`：4名NPC的功能、材料、奖励、完整对白与替代关系。

## 二、执行顺序

1. 先运行本地测试：`node --test tools/game-design/c1-actual-data.test.mjs`。
2. 在玄渊平台预检怪物表，只处理怪物库与现有MonGen名称/颜色；该表不新增刷怪点。模型库编号留空是平台稳定随机，不是数据缺失。
3. 预检装备表。按表头字段名读取，禁止按旧版列号复制；新版第28列是“回收增加”，旧版“持久”不得错位带入。
4. 备份现有MonItems后，比对并复制`MonItems_GBK`；36个文件必须逐个对应36只怪物。
5. 根据4份NPC TXT生成脚本。只从实际可行走点选择坐标，不得猜坐标；脚本完成后回填地图号、坐标、变量号和事务号。
6. 每一步先预检，确认阻断项为0后再提交；提交后记录事务号并进服抽测普通怪、稀有怪、地图BOSS和守关BOSS。
