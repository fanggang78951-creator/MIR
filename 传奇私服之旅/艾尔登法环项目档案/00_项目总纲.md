
# 00 项目总纲

## 项目定位

本项目是基于翎风/LFM2单引擎的《艾尔登法环》传奇版本。`E:\XuanYuanDevPlatform` 是可复用成果母库，`D:\MirServer` 是当前正式部署目标；GitHub 私库保存可读档案、脚本快照、接口、配置与验证报告，不替代游戏内验收。

## 本轮权威范围

只收录脚本和功能：战斗计算、处决与韧性、技能强化、称号/转生/神印、狂暴/捐献、回收、洗练开光、图鉴、合成、活动、副本、背包服务、UI属性显示等。

明确排除地图与装备内容：地图号/坐标/连接/MAP资源、装备来源编号、装备属性设计和数据库内容均不在本轮结论内。

## 事实优先级

1. 当前正式服文件与 `.xydp/installed.json` 收据。
2. 平台成果包 `manifest.json`、证据文件、接口文档和中文配置母表。
3. `D:\codex交班记录` 索引中的最新验收记录。
4. 设计问卷只用于仍有效的设计规则，不能覆盖实际部署事实。

## 状态定义

- 设计定稿：规则明确且已有游戏证据，但当前正式服收据未登记该包。
- 已写入文件：平台已有候选源码，尚无当前正式服安装收据。
- 已部署待实测：正式服收据存在，但当前版本未形成完整游戏验收闭环。
- 游戏内实测通过：平台证据明确记录游戏验收；仍需关注正式服是否正是同一版本。
- 已废止：测试或过渡功能，不应再次安装。
- 仍待确认：现有文件不能给出唯一结论。

## 施工原则

统一使用 `detect → preflight → plan → apply → verify → rollback`。共享脚本按受管块合并，冲突默认阻止；保留GB18030/CRLF目标格式；用户游戏验收前保持candidate。地图、装备内容若以后恢复归档，必须另开任务，不能混入本次权威结论。
