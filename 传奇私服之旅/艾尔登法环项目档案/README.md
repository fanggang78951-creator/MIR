
# 《艾尔登法环》传奇项目权威档案

本目录是《艾尔登法环》传奇项目在 GitHub 中的权威资料区。本轮按用户最终要求，只归档**脚本类与功能类**成果。

不在本轮范围：地图台账、地图号、坐标、客户端 MAP 资源、装备来源编号、装备内容与装备数据库。装备回收、洗练、图鉴、合成等保留为功能系统，但不盘点具体装备设计。

## 入口

- `00_项目总纲.md`：边界、事实来源和维护规则。
- `01_当前任务指针.txt`：下一步唯一工作指针。
- `02_已确认规则与数值.xlsx`：已确认的脚本规则、公式和状态口径。
- `03_变更记录.md`：被推翻方案与当前替代关系。
- `04_每日设计更新.md`：本轮归档更新。
- `05_当前有效游戏设计总档.md`：仍有效的脚本/功能方案。
- `06_脚本功能总台账.xlsx`：功能、版本、状态、证据和漂移。
- `脚本与功能/`：正式服快照、接口、母表、成果包与审计报告。
