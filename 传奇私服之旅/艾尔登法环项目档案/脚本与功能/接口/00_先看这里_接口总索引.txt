一、这个文件夹解决什么问题

这里集中记录平台当前真正保留的“对外调用入口”和“内部接入契约”。
以后制作 NPC、屏幕图标、任务、活动、装备或新成果包时，先查这里，不要从旧交班记录、测试服 QFunction 或历史脚本中猜接口。

这里是接口说明库，不是可执行脚本目录。复制本目录中的示例不会自动安装功能；正式植入仍需在玄渊成果平台中预检、确认安装和验收。

三、接口等级

[公开]
允许 NPC、屏幕图标、任务或菜单按说明调用。调用者只负责进入接口，不得复制核心扣费、奖励、状态或伤害逻辑。

[受限]
只允许在指定文件、事件或平台受管块中调用。常见限制是“只能在 QFunction 内 GOTO”或“只能用外部脚本 #CALL”。

[内部]
属于平台、成果包、做装备工具或事件链的实现契约。可以用于维护和校验，但不得直接做成玩家按钮/NPC选项。

[实验室]
只供隔离测试。未转成正式成果包前不得接入正式服。

[禁止]
已经确认错误、过时、冲突或只为临时验收存在。不得复制到新成果。

五、权威来源顺序

1. packages\verified 或 packages\candidate 中当前唯一包 ID 的 manifest.json；
2. 同一成果包的当前 README/使用说明；
3. 同一成果包的验收证据；
4. labs 只代表实验室；legacy_archive、testbeds、backups 和旧交班记录不得作为当前接口母版。

同一包的 README 版本号与 manifest 不一致时，以 manifest 为准。例如世界地图当前清单为 1.0.0-candidate.21，README 标题内仍有 candidate.20 的旧文字，不得据此降级接口。

六、统一安全规则

1. 新入口先安装并验收它依赖的成果包。
2. QFunction 内部公共标签使用 GOTO；外部 QuestDiary/NPC 文件只有在文档明确给出时才使用 #CALL。
3. 不允许把完整业务逻辑复制到 NPC、按钮或任务脚本。
4. 不允许自行占用 UserCmd 编号、CustomButtonID、Buff ID、变量名或装备锚点。
5. 不允许直接把 MAPMOVE 当作世界地图授权入口。
6. 不允许在点击/授权脚本里重复执行 VAR；世界地图变量只在登录入口声明。
7. candidate 接口必须在独立测试服完成游戏验收后再作为正式玩法发布。
8. 修改现有受管块前必须由平台预检；手工改过且哈希不匹配时停止，不猜测覆盖。
9. 百分比吸血与每秒回血使用 xy.combat.sustain 的内部受管接口；吸血通过共享 `[@Attack]` 事件按对怪实际伤害即时回血，不占持续状态，不得接入PVP；该包独占个人定时器 `OnTimer19`，NPC、按钮和玩家命令不得调用或复用。每秒回血数值必须由XLSX生成到QManage固定`HumanHP + 数值`，不得恢复动态变量传值旧路线。

七、当前明确没有的接口

1. 快捷回收没有可跨文件 #CALL 的 NPC 核心接口；当前引擎已实证该路线 load fail。
2. 技能强化没有 NPC/聊天命令入口，玩家唯一入口是技能面板升级按钮。
3. 国王模式不提供通用玩家命令，报名和管理必须走其成果包生成的 NPC。
4. 初始背包 200 格不是玩家命令，只是登录脚本契约。
5. 首爆没有手动领取命令，只在 PickUpItemEX 拾取事件触发。
