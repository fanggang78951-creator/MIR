# 三组属性面板锚定与发布标准

## 总原则

**业务脚本负责计算，显示脚本只负责读取。**

属性图标不得重复执行`POWERRATE`、伤害、爆率、吸收或处决计算。优先读取业务包维护的稳定最终变量；只有业务链没有可靠汇总变量时，才允许用声明式`equipment_additions`镜像同一组已经验证的`CHECKITEMW`装备分支。

## 声明接口

三个安装参数`panel_a`、`panel_b`、`panel_c`使用同一结构：

| 字段 | 规则 |
|---|---|
| `title` | 最多20字符，不得含脚本保留字符 |
| `title_color` | 0–255 |
| `namespace` | 英文字母开头，只能含字母、数字、下划线；三组必须不同 |
| `items` | 1–12项，顺序就是悬浮顺序 |
| `label` | 显示名称 |
| `source` | 唯一业务变量，例如`N$XY_最终爆伤` |
| `read_mode` | `source`读最终变量、`bind`读装备属性位、`zero`从0开始；省略时自动选择 |
| `bind_type` | `read_mode=bind`时必须提供；其他模式可保留为属性位说明 |
| `equipment_additions` | 可选装备同源规则数组，每条只含`name`、`amount`、可选`count` |
| `offset` | 显示前扣除的基准值，默认0 |
| `divisor` | 显示除数，默认1；只允许正整数 |
| `prefix`/`suffix` | 数值前后文本 |
| `color` | 行颜色，默认251 |
| `clamp_min` | 可选最小显示值 |

`namespace=A`会生成`N$XY_UI_A_Value01...`，B和C生成各自变量，禁止三组复用同一镜像变量。

## 当前默认锚定

| 图标 | 显示项 | 来源 | 转换 |
|---|---|---|---|
| A | 神力倍攻 | `N$倍攻` | `source`，减100；禁止直读40 |
| A | 伤害系数 | BindType 53 | `bind`，原值 |
| A | 暴击伤害 | BindType 42 | `bind`，原值 |
| A | 打怪伤害 | `N$XY_PVE` | `source`，减100；禁止直读41 |
| B | 首刀斩杀 | `AttackDamage`装备分支 | `zero`加测试鞋子、尾刀盾牌分支 |
| B | 尾刀斩杀 | `AttackDamage`装备分支 | `zero`加测试鞋子、首刀马牌分支 |
| B | 鞭尸概率 | BindType 13及`KillMon`装备分支 | `bind`后累加同源分支 |
| B | 对怪吸收 | `RecalcMonsterAbsorb`装备分支 | `zero`加测试腰带10；图标保持短名称 |
| C | 韧性 | BindType 50 | `bind`，原值 |
| C | 处决概率 | BindType 49 | `bind`，10显示10% |
| C | 处决时间 | BindType 52 | `bind`，1显示1秒 |
| C | 处决倍数 | BindType 51 | `bind`，原值百分比 |

处决时间和处决倍数显示的是装备提供的PVE增量；按既定规则不进入PVP实效。

## 刷新标准

- 登录、穿戴、脱下先立即刷新，再固定延迟5拍补绘，给业务重算留下顺序。
- 攻击后刷新A和处决相关变量，击杀后刷新鞭尸变量。
- 新业务变量变化后调用公开标签`@XYDP_ShowAttrBuff`。
- 参数10不得包含普通空格；悬浮多行使用反斜杠。
- 平台清单和payload为UTF-8，写入服务端为GB18030/CRLF。
- 属性A的正式坐标为左246、上17；91号动态按钮必须与大画布静态占位重合。
- 旧88号属性测试按钮和`XYTEST_ATTR_BUFF_LOGIN`只允许标记为禁止参考，不得重新接入登录流程。

## 发布门槛

必须分别验证变量真实值、悬浮显示值和游戏实效，三者一致后才能晋级verified。显示正确不能替代实效验收，实效正确也不能替代显示验收。
