# 2.0.1 运行桥接修复证据

## 已复现问题

- 旧版QFunction桥接标签与外部脚本业务标签同名，装备变化后出现`GOTO @XY_UI_STATUS_EQUIP_CHANGED`脚本死循环，导致属性刷新链中断。
- 界面静态狂暴和世界地图按钮分别发送`CustomButtonID=3`与`CustomButtonID=5`，旧版错误接到了`ButtonClick89`等动态按钮事件，因此点击无反应。
- 旧版只要检测到一件复活装备就固定显示2次，与实际装备数量不符。

## 修复契约

- QFunction桥接统一使用`XY_UI_QF_*`，外部脚本使用`XY_UI_*`，名称完全分离。
- `CustomButtonClick`中ID 3调用狂暴确认入口，ID 5转发既有`@ButtonClick88`世界地图入口。
- 复活次数按配置名单中的有效佩戴件数计算并封顶2；一件不补发脚本复活，两件才补发一次。
- 穿戴与脱下在业务重算后第6拍刷新显示变量。

## 自动验证

- 35项五图标、可配置属性和文本事务测试全部通过。
- 隔离副本安装后五个`XY_UI_QF_*`桥接标签及`CustomButtonClick`各唯一一处，旧同名QFunction标签为0。
- 安装后重复预检0变更；回滚后QFunction与主脚本SHA-256逐字节恢复。
- 正式目标事务：`20260725_185715_ab966b05`；安装后第二次预检0变更。
