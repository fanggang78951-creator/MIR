# 按有效佩戴数共享复活静态契约

- 原生配置：`RevivalTime=60000`。
- 有效佩戴数：按配置名单中实际穿戴的复活装备统计，封顶2；一件对应1次，两件对应2次。
- 第1次机会：只要佩戴至少一件有效装备就由引擎原生复活，触发`[@Revival]`。
- 第2次机会：只有统计为2件时，才在`[@Revival]`后执行`SetReborn 1 <$REVIVALTIME>`；一件时禁止补发。
- 第2次消耗：触发`[@NpcRevival]`后，图标转为黑白并读取原生剩余冷却。
- 图标彩色条件：原生冷却为0，或本包拥有且`<$NpcRebornCount>`大于0。
- 图标黑白倒计时条件：已佩戴有效复活装备、原生冷却大于0、本包额外机会已经消耗。
- 不建立独立复活冷却，不执行`SetReborn 2`。
