# 对怪伤害吸收与上限游戏验收

- 日期：2026-07-25
- 验收来源：用户在当前测试端完成 `@UserCmd92` 全部测试后明确反馈“所有数值都通过”。
- 已通过：20%、50%、85%怪物伤害吸收。
- 已通过：后调用覆盖前状态；1%/1秒探针可清除旧状态。
- 已通过：重登后重新施加有效。
- 已通过：PVP伤害不受影响。
- 已通过：宝宝/宠物伤害不进入本属性。
- 正式包不包含 `@UserCmd92`、测试菜单或实验标签。

正式计算：

```text
候选吸收 = 全身“对怪伤害吸收”之和
有效上限加成 = min(全身“伤害吸收上限”之和, 25)
最终上限 = 60 + 有效上限加成
实际吸收 = min(候选吸收, 最终上限)
```

正式脚本每次只向引擎提交一个最终吸收值。装备归零时使用已验收的1%/1秒覆盖探针；持续状态以300秒为单次周期，并在在线期间每240秒刷新。
