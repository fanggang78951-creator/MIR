# 升级自动三级基础技能沉淀依据

- 当前翎风服 `Magic` 表确认的经典基础技能共33项：战士6、法师14、道士13，初学等级均不超过35级。
- 玩家已确认原逻辑可以发放技能；界面出现“强化三重”的根因是把末参数 `1` 当成普通技能等级使用。
- 正确契约：`CHECKSKILL 技能 < 3 0` 与 `SKILLLEVEL 技能 = 3 0`。末参数 `0` 是普通技能等级，`1` 是强化技能等级。
- `ADDSKILL 技能 3` 用于尚未学习时直接发放普通三级技能。
- 登录入口只负责历史角色与漏发兜底；`QFunction-0.txt[@PLAYLEVELUP]` 才负责达到等级当刻立即补发。
- 2026-07-16 当前服M2自动重启后，最新日志 `script error=0`、`load fail=0`、`database locked=0`。
- 当前包不包含“强化三重误发修复名单”等一次性迁移代码，避免把历史故障修复带到全新服务端。
- 游戏内跨等级即时获得仍待最终回报，因此本包保持 `candidate`，但 `residency=resident`，会进入一键常驻安装预检。
