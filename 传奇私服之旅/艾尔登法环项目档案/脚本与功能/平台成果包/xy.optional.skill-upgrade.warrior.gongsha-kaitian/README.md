# 战士技能强化：攻杀剑术→开天斩

这是已经过游戏内验收的独立非常驻成果包。

- 成果包：`xy.optional.skill-upgrade.warrior.gongsha-kaitian`
- 版本：`1.0.0`
- 状态：`verified / optional`
- 不参加“一键安装常驻基础”
- 安装时必须同时选择服务端根目录和客户端 `data` 目录
- 不创建 NPC、不发放测试物品、不保留实验室标签

## 玩家入口

玩家先把攻杀剑术练到普通 3 级，然后在人物技能面板点击攻杀剑术右侧的升级按钮。每次只升一级，强化 9 后保留攻杀剑术强化 9，并自动学习普通 3 级开天斩。

若角色已达到攻杀剑术强化 9，但开天斩缺失或低于普通 3 级，登录时会自动补齐。

## 正式费用

本版严格保留通过游戏验收的低费用配置：强化 N 级消耗金刚石 N 个、血剑碎片 N 个、元宝 `10×N`、账户金刚石 N 个。任何经济数值调整都必须另做版本并重新游戏验收，不能直接改本包。

## 平台安装

在“成果包库”选择本包，先选择目标服务端和客户端 `data` 目录，再点“生成预检报告”；预检通过后点“确认安装”。平台会事务修改：

1. `ApexM2.DB` 中普通攻杀剑术的升级开关；
2. `QFunction-0.txt` 的强化与领悟逻辑；
3. `QManage.txt` 的登录补写调用；
4. 独立登录补写脚本；
5. 客户端 `SkillUpgradeDesc.Dat` 的强化说明。

安装前需按平台现行规则手动停止 M2。安装失败不会留下半成品，安装历史可逐字节回滚。
