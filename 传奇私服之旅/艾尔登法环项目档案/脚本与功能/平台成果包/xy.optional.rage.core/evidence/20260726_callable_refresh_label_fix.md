# 狂暴刷新接口可调用标签修复

- 现象：M2 报 `狂暴界面刷新接口.txt@XY_RAGE_UI_REFRESH` 加载失败。
- 根因：旧平台用普通事件空桩生成了 `[@XY_RAGE_UI_REFRESH]`，缺少被 `#CALL` 调用的子程序所需 `{ ... }` 边界。
- 修复：狂暴包改用 `ensure_callable_label`；仅把正文严格等于 `#IF/#ACT/BREAK` 的旧空桩安全迁移为带花括号的可调用标签，保留属性图标受管刷新钩子。
- 防回归：事件钩子识别可调用标签后插入花括号内部；普通 QFunction 事件仍沿用 `ensure_event_label`，不会被误加花括号。
- 验证：可调用标签创建、旧空桩迁移、未知正文阻止、钩子幂等、隔离安装与逐字节回滚均由自动测试覆盖。
