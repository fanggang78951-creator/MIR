# 第一大陆·漂流群岛魂魄任务

这是三个相互独立、每个角色只能完成一次的地图任务。

- `XX113 (116,104)`：拾骸女·梅芙，任务“海岸亡魂”。
- `XX329 (78,55)`：断誓骑士·罗恩，任务“风暴遗誓”。
- `XX104 (85,23)`：无冠史官·塞蕾，任务“沉王终曲”。

每个任务按“材料齐全 → 先授予称号 → 确认称号存在 → 再扣除材料”的顺序执行。称号既是奖励，也是该角色的一次性完成标记；已经获得称号时不再显示提交按钮，也不会重复扣除材料。

每个称号的数据库属性为攻击、魔法、道术各 `30-30`。韧性通过平台现有的 `XY_EXECUTION_LAB_TOUGHNESS_ANCHOR` 接入，每个称号增加20；三个称号同时拥有时累计为韧性60、攻魔道90-90。

安装必须选择服务端与对应客户端根目录。客户端用于写入 `data/fenghao.dat` 的称号说明。包状态为 `candidate`，需完成 M2 无报错、三任务游戏内验收和回滚验证后再晋级。
