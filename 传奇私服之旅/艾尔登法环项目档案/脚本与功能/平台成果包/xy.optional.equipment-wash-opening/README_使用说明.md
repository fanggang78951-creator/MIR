# 装备洗练与开光（verified 1.0.0）

这是用户于2026-08-08在游戏内验收通过的正式母版，平台包ID：$packageId。

## 功能

- 装备洗练：沿用77boss已验证概率和词条，默认每次100元宝。
- 装备开光：天赐、神佑首次开光免费；重复开光收取50个失色锻造石。
- 操作台：640x360不透明可拖动背景，76x76不透明装备槽。
- 放入装备后图标继续显示，不重新打开或刷新窗口。
- NPC名称、脚本路径、地图、坐标和外观均可在安装参数中修改。

## 安装

成果包库选择“装备洗练与开光（可拖动绝对坐标操作台）”，填写两个NPC参数，服务端和客户端路径必须同时选择，然后生成预检报告。预检通过后再确认安装。

安装会写入：两NPC脚本、四个洗练/开光核心、MerChant两行、EffectImageList唯一行及客户端独立WZL/WZX。任一地图不存在、NPC注册冲突或客户端路径缺失都会阻止。

## 正确布局标准

- ITEMBOX必须是#SAY第一个元素。
- 标题、说明、按钮必须使用<&Text>绝对坐标；普通<Text>会按文本流累加偏移。
- @ItemIntoBox27/28只BREAK，禁止重新OPENMERCHANTBIGDLG或#SAY。
- WZL/WZX必须成对安装，EffectImageList固定登记XY_EquipmentWorkbench.wz。

## 验收与回滚

安装后检查NPC显示、窗口拖动、槽位对齐、装备放入可见、洗练、首次/重复开光及关闭返还。安装历史页可逐字节回滚。
