# 通用装备、材料、物品合成

本成果包由 `34_通用物品合成.xlsx` 提供配方，由 `35_合成NPC与配方分配.txt` 决定地图、NPC和配方归属。支持任意数量的地图和独立NPC、任意数量的物品输入和原生货币输入，并产出目标服已有的装备、材料或普通物品。

- 每个配方在“合成配方”中占一行。
- A、B、C……全部消耗在“消耗明细”中逐行填写，没有固定上限。
- 产出数量留空时默认1个。
- 金币、元宝、灵符、金刚石使用引擎原生货币命令。
- 同一地图可放多个合成NPC，不同地图可配置各自的NPC；每个NPC只显示分配给自己的配方。
- NPC主页面右侧按目标服真实 `StdItems.Idx` 显示本页合成产物；鼠标悬停直接查看该物品的真实属性，不复制属性说明，也不修改装备数据库。
- 每个启用配方必须且只能归属一个启用NPC，漏配和重复分配均会阻止安装。
- 物品输入和产出名称必须在目标服 `StdItems` 中唯一存在。
- 安装只写每个NPC的独立受管脚本及 `MerChant.txt` 唯一注册行。
- 先预检、再确认；预检后任一配置变化都会阻止安装；安装失败可逐字节回滚。
