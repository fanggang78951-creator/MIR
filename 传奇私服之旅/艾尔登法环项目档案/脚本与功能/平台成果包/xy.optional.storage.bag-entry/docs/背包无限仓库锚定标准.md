# 背包无限仓库锚定标准

## 固定接口

| 项目 | 固定值 |
|---|---|
| 客户端控件 | `DBagCustomButton1` |
| 服务端按钮ID | `20` |
| 事件标签 | `[@CustomButtonClick]` |
| 引擎命令 | `OpenStorageView 1` |
| 目标文件 | `Mir200/Envir/Market_Def/QFunction-0.txt` |
| 编码与换行 | GB18030/GBK，保留目标文件CRLF |

## 适用条件

M2已经在“功能设置”中启用无限仓库，并设置有效容量。当前服 `!setup.txt` 可见 `BigStorageLimitCount=100` 与 `BigStorageSaveItems=100`，但包本身不拥有也不改写这些配置。

## 禁止事项

- 禁止用 `OpenStorageView 0` 代替无限仓库。
- 禁止把按钮20和按钮21合并到同一功能。
- 禁止修改 `Mir.ui`、PAK、登录器或仓库数据库来实现此入口。
- 禁止在编号20已经被占用时追加第二个条件分支。

## 晋级门槛

必须具备静态检查、M2无脚本错误、游戏内存入/取出/重登持久性、逐字节回滚四类证据，才能从candidate晋级verified。
