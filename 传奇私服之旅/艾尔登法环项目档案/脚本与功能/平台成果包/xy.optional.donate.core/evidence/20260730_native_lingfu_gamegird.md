# 原生灵符 GAMEGIRD 静态证据

- 默认捐献配置使用`消耗类型=原生灵符`、`消耗名称=灵符`。
- 核心按配置数量计算`N$XY_DONATE_COST_THRESHOLD=数量-1`，使用`CHECKGAMEGIRD > 门槛`检查，刚好足够可通过。
- 扣除统一使用`GAMEGIRD - 数量`。
- 为兼容旧配置，`消耗类型=材料`且`消耗名称=灵符`同样进入原生GAMEGIRD分支；普通材料分支明确排除灵符，不会回退到`CHECKITEM/TAKE`。
- 核心安装改为UTF-8源转GB18030/CRLF，避免M2按本地编码读取中文配置键时乱码。
- 当前仍需游戏内验证不足、刚好足够、累计、榜一和封榜。
