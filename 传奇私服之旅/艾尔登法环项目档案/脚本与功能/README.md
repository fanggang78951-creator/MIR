
# 脚本与功能目录

- `快照/正式服原始脚本`：与正式服逐字节一致，用于哈希和回滚核对。
- `快照/正式服脚本UTF8`：同一脚本的UTF-8可读副本，便于GitHub和ChatGPT检索。
- `平台成果包`：平台当前功能包的清单、脚本和证据；不含客户端二进制资源。
- `接口`：筛选后的公共命令、事件、UI和NPC接入说明。
- `配置母表`：脚本功能所需的中文XLSX/TXT/CSV；不含地图和装备内容母表。
- `报告`：功能、托管块、脚本、接口、配置、版本漂移和静态问题台账。
- `工具`：只读审计与文档生成工具。

原始快照用于证明正式服当前状态，UTF-8副本用于阅读；二者SHA-256对应关系见`报告/脚本文件清单.csv`。
