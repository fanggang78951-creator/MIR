玄渊成果平台——需要用户填写的文档总说明（当前版）

正式填写目录：D:\XuanYuanDevPlatform\所需材料表格汇总

一、最重要的规则

1. 从本版开始，只编辑本目录中的中文文件。
2. 做装备、技能、地图规则和成果包仍保留原来的旧文件，作为旧版本兼容副本；不要再编辑旧副本。
3. 当前平台优先读取本目录中文母版；中文母版缺失时才回退旧路径。因此归拢不会导致原按钮、CLI或成果包失效。
4. 编辑XLSX后必须保存并关闭WPS/Excel，再到平台点击预检。
5. 平台预检只读；确认安装/生成后才会备份并写入目标服。

二、全部填写文件

01_狂暴.xlsx
  用途：初始营地狂暴NPC的名称、位置、外观和业务配置。
  入口：NPC编辑 -> 初始之地七NPC。

02_捐献.xlsx
  用途：捐献NPC与捐献配置，调用平台唯一捐献核心。
  入口：NPC编辑 -> 初始之地七NPC。

03_赞助称号.xlsx
  用途：赞助称号档位、原生货币消耗和属性。
  入口：NPC编辑 -> 初始之地七NPC。

04_转生.xlsx
  用途：逐级转生称号、材料、货币和属性。
  入口：NPC编辑 -> 初始之地七NPC。

05_圣律之剑.xlsx
  用途：圣律之剑逐级兑换链，只填写上下级装备名和消耗；属性读取目标服真实装备库。
  入口：NPC编辑 -> 初始之地七NPC。

06_黄金圣物.xlsx
  用途：黄金圣物逐级兑换链，只填写上下级装备名和消耗；属性读取目标服真实装备库。
  入口：NPC编辑 -> 初始之地七NPC。

07_新手礼包.xlsx
  用途：礼包码、奖励装备和NPC配置。
  入口：NPC编辑 -> 初始之地七NPC。

08_地图外显与多层传送.xlsx
  用途：地图外显名、多层地图连接、入口/出口和安全区配置。
  入口：玄渊界面施工台的地图功能。

09_装备批量生成.xlsx
  用途：生成新装备。表格填写的属性就是最终装备属性。
  入口：批量做装备 -> 预检/确认生成。

10_装备属性修改.xlsx
  用途：按名称修改已有同名装备定义。只保留要修改的装备行。
  入口：批量做装备 -> 预检修改/确认修改。

11_材料批量生成.xlsx
  用途：生成可叠加材料及客户端图标资源。
  入口：批量做装备 -> 预检材料/确认添加材料。

12_战士技能强化.xlsx
  用途：配置原技能、强化等级、每级消耗和强化9后解锁技能。
  入口：战士技能强化实验室；命令未指定--config时默认读取本文件。

13_地图怪物处决规则.csv
  用途：按地图填写韧性要求、怪物处决基础概率和档位规则。
  状态：处决怪物地图试点配置，验证后再正式沉淀。

14_国王模式配置.txt
  用途：国王模式的地图、时间、队伍、复活、奖励等默认配置。
  入口：国王模式独立页面。新目标服和缺失配置项从本文件读取；目标服已有自定义值仍优先保留。

15_首爆奖励配置.txt
  用途：首爆奖励配置。
  入口：成果包xy.ops.first-pick。新安装优先读取本文件；目标服已有配置不会被覆盖。

16_复活图标装备名单.txt
  用途：配置哪些装备提供复活次数，以及对应次数。
  入口：成果包xy.ui.attr-overview。新安装优先读取本文件；目标服已有配置不会被覆盖。

17_装备悬浮分类.xlsx
  用途：给目标服已有装备批量补齐或修改悬浮分类，不修改装备属性。
  分类合同：制式装备=1,2,3；稀有专属=1,2,4；追梦神器=1,2,5；不处理=跳过。
  入口：批量做装备 -> 预检悬浮 -> 确认同步悬浮。
  附带内容：统一同步已验收的艾尔登法环动画底标和 XY_ItemHint.wzl/wzx；服务端与客户端纳入同一事务回滚。

20_怪物批量生成.xlsx
  用途：只填写怪物名称、等级、经验、血量、防御、魔防、最小/最大攻击和命中。
  模型：模型库编号可以留空，由平台从完整怪物库稳定随机选择外观和动作。
  入口：怪物库 -> 预检生成表 -> 确认批量生成。
  自动处理：PAK、WZL/WZX、图库号、密码和登录器规则都由平台管理，不在表格填写。
  边界：不生成爆率、MonGen刷怪、地图、技能或独立AI脚本。

21_神印基础属性.xlsx
  用途：按200层锻体规划逐级增加人物基础攻击、魔法、道术和HP。
  当前：200层已按用户源表完整填写，状态为可安装；材料为逐层增加的野兽骨片。
  规则：表中属性是本层完成后的累计总值，平台自动计算相邻两层差值；只使用ChangeHumAbilityEX 5至11，不授予称号，不进入任何乘区。
  入口：NPC编辑 -> 神印与称号双NPC。

22_称号晋升.xlsx
  用途：10级称号逐级晋升，只显示玩家当前可进行的下一档。
  当前：名称、攻魔道、HP、MP、基础爆率、神秘符文、金币和元宝均已填写；称号编号固定使用100至109，10行状态为可安装。
  规则：MP逐档与HP相同；编号已核对当前目标服和平台登记未占用，但每次安装前仍会重新预检；高级称号确认授予成功后才扣费并回收低级称号。
  入口：NPC编辑 -> 神印与称号双NPC。称号启用后必须同时选择客户端以同步fenghao.dat。

34_通用物品合成.xlsx
  用途：配置装备、材料、普通物品A+B+C……再加原生货币，合成目标服已有物品。
  配方：每个配方在“合成配方”占一行；全部消耗在“消耗明细”中按相同配方ID逐行填写，没有固定A/B/C列数。
  数量：产出数量留空时默认1；填写其他正整数时按填写数量产出。
  货币：输入类型选“货币”后，只允许金币、元宝、灵符、金刚石；均调用引擎原生货币。
  入口：选择配置文件预检/植入 -> 选择本文件 -> 预检 -> 确认植入。
  状态：示例默认关闭；完成真实游戏验收前保持candidate。

三、七NPC表格通用规则

1. “待配置”的行不会扣材料、给属性或执行升级；配置完整后改为“可安装”。
2. X/Y均写“自动”或同时留空时，平台会从xycamp出生点25,28附近寻找空闲位置。
3. 狂暴、捐献只调用平台唯一公共核心，不复制第二套逻辑。
4. 赞助与转生采用称号链；高级称号授予成功后才回收低级称号。
5. 圣律之剑和黄金圣物每级只收表格中的上一级装备、材料和货币，不在脚本中写死装备属性。
6. 真正空白的单元格必须清空；“43”“44”等占位文字会被当成真实物品名和数量。

五、神印与称号双NPC规则

1. 21号表必须保留完整1至200层，22号表必须保留完整1至10级，不允许删除中间档。
2. 同一张表的状态必须全部为待配置或全部为可安装，禁止半套启用。
3. 21号表的属性是累计总值；平台自动计算本次增量。属性下降、档位断层或资源为空时阻止。
4. 22号表的称号编号必须0至255且10档唯一；名称也必须唯一。
5. NPC名称、地图、外观每行保持一致；X/Y均写自动时平台自动寻找可走且未占用坐标。
6. 当前模块是独立candidate，不会在验收前替换旧xy.ops.title。

六、推荐操作顺序

1. 在本目录找到对应中文文件。
2. 编辑并保存，关闭WPS/Excel。
3. 打开平台相应页面，确认显示的文件路径仍在“所需材料表格汇总”。
4. 点击预检，先处理所有阻止项。
5. 核对修改文件和摘要差异后再确认。
6. 游戏内验收通过后保留安装收据；不合格则使用平台回滚。
