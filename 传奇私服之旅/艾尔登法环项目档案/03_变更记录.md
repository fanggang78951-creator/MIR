
# 03 变更记录

| 原方案 | 替代方案 | 当前结果 |
|---|---|---|
| 打怪伤害使用不稳定的 `POWERRATE type2` | 使用已验证的 `ChangeDamageValue` 路线 | 当前有效；旧路线禁止参考 |
| “最大爆率”理解为独立上限 | 普通爆率与最大爆率按倍率相乘 | 500%与500%按 `(1+5)×(1+5)=36倍` 口径；当前有效 |
| 狂暴、捐献存在多套重复逻辑 | 每个系统只保留一个核心，NPC/图标只调用公共命令接口 | 当前有效；重复后门和第二套核心废止 |
| 灵符按背包物品处理 | 灵符统一使用引擎原生货币命令 | 当前有效；物品式灵符路线废止 |
| 转生仅用脚本称号变量模拟 | 转生进度依托引擎原生转生，称号只作显示镜像 | 游戏验收通过并已沉淀 |
| 逐级系统展示全部等级列表 | 只展示当前可升级的下一档，成功后刷新 | 转生、称号、成长/合成类默认规范 |
| 对玩家显示“哈希变化、资源已变化、引擎”等制作术语 | 所有提示改为玩家视角游戏语言 | 当前强制规范 |
| 项链幸运强化附带幸运15处决/伤害系数绑定 | 只沉淀项链强化主体，额外绑定不更新成果包 | 用户最终确认；绑定实验不作为正式包能力 |
| 装备收集测试重置包长期保留 | 仅保留正式图鉴，测试重置包标记废止 | `xy.optional.equipment-collection.test-reset` 已废止 |
| 本次建立地图与装备来源台账 | 只建立脚本与功能档案 | 用户最终范围，地图/装备内容隔离出本轮成果 |
