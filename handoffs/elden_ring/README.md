# 《艾尔登法环》Codex统一交班目录

这个目录是主设计读取各Codex窗口状态的固定入口。以后不再从各自产物目录中猜测哪份文件是最新交班。

## 直接读取入口

- 平台应用窗口：`handoffs/elden_ring/current/platform_app.md`
- 脚本窗口：`handoffs/elden_ring/current/script.md`
- 后续新增窗口：在 `current/` 下使用稳定英文文件名，例如 `map.md`、`ui.md`

主设计默认先读 `current/`；只有需要追溯时才读 `history/`。

## 每次任务必须写两份

1. 更新本窗口固定的 `current/<window>.md`，始终保存最新状态。
2. 在 `history/<window>/` 新建一份不可覆盖的历史记录，命名格式：

   `YYYY-MM-DD_HHMM_任务简称_提交SHA前7位.md`

如果提交SHA尚未生成，先在正文写 `提交SHA：待提交`，提交后再补齐；历史文件名可以使用本轮事务号或任务编号代替SHA。

## 交班记录固定内容

- 窗口名称、任务单路径、状态、开始/完成时间、分支、提交SHA。
- 本轮实际完成内容和数量。
- 新建/修改文件的仓库相对路径。
- 数据库、平台或服务器有实际修改时，写备份位置、事务号和验证结果。
- 编号、地图、坐标、怪物、装备或公式检查结果。
- 未完成项、阻断原因和具体对象，不能只写“有问题”。
- 交给下一个窗口的文件路径和下一步动作。

## 并发规则

每个窗口只修改自己的 `current` 文件和自己的 `history/<window>/` 目录。共享成果放在任务指定的输出目录，避免多个窗口同时覆盖同一交班文件。
