# 装备来源编号分配说明（2026-09-05）

## 最新规则
- 优先使用未占用的同资源部位编号。
- 编号不足时允许复用，但仅能复用同资源部位的编号。
- 同一大陆、同一资源部位不得使用同一编号。
- 复用优先跨至少3个大陆；最低保持2个大陆距离。
- 分配顺序采用固定随机种子 202609052314 打乱，避免C1使用ABCD、后期继续按ABCD顺序机械复刻。

- 原464件中的7096—7217类补号超出当前权威装备资源库7095上限，本轮已全部替换为真实资源库范围编号。
