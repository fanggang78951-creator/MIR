# 2026-09-05 人物幸运与数值尺度修订说明

## 1. 幸运
项链幸运从“绑定当前项链”修正为“绑定人物”。人物累计完成幸运过程并达到项链幸运8后，后续更换项链不丢失、不重新付费。武器幸运仍按7计入有效幸运，但武器幸运获取成本忽略。因此C2半急速毕业起，基准人物有效幸运按15处理（武器7+人物项链8），并继承到后续大陆。

## 2. 数值尺度
金币/元宝：所有已建模系统产出与消耗 ×100。
失色锻造石：所有已建模专属分解/产出与洗练、开光、合成等消耗 ×10。
其他材料数量、人物属性、掉率概率、洗练权重、成功率、50%货币回收加成均不因本次尺度修订改变。

这相当于8÷4=2改成80÷40=2。货币等价小时原则上不变。人物累计账若因幸运永久化、取消武器幸运成本而变化，不属于倍率偏差。

## 3. C2主城
C2是全游戏长期系统的主要功能中心。除C2贯穿称号与本地装备合成外，长期NPC使用的核心资源应在后续大陆持续产出，不应离开C2就断供。561怪掉率施工时，把神秘符文、失色锻造石、野兽骨片以及现有技能/幸运长期资源纳入后续贯穿掉落池，再按需求闭环决定1/x。

## 4. 角色模型影响
C1尚未完成项链幸运时，有效幸运主要来自武器7；C2完成后人物项链幸运8永久继承。最新版40组人物已重算，不再对每次换项链重复计算幸运成本。

## 5. 非现行基准
21765灵符是用户实测的早期灵符极限支出记录，但不与12小时、免费毕业时间或货币价值做固定换算。相关讨论冻结，待整体掉落/产消完成后另行校准。
