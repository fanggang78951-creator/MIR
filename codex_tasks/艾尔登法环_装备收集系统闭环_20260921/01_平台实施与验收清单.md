# 装备收集系统｜平台实施与验收清单

## A. 安装前预检
- [ ] 619个正式装备名在目标StdItems中全部唯一解析。
- [ ] 收集ID 4—622连续、唯一；1—3停用。
- [ ] 46个分类ID唯一，且每个正式收集ID只属于一个分类。
- [ ] 10大陆关联总计619项，数量分别38/61/80/80/80/44/44/56/68/68。
- [ ] 单件、地图组、大陆完成三类持久状态的实际存储互不重叠。
- [ ] `@装备收集` / UserCmd 92不覆盖目标服已有命令；冲突则由平台重新分配。
- [ ] 永久属性适配器明确处理“暴击几率”；不能落成暴击伤害。
- [ ] 用户处理后的最大收集ID容量允许622。

## B. 单件登记事务
- [ ] 未登记+背包有1件：恰好扣1件、发本行奖励、设置单件状态。
- [ ] 未登记+背包无装备：不扣、不发、不记状态。
- [ ] 已登记再次点击：不扣、不发。
- [ ] 连点/重复包：不产生双倍奖励。
- [ ] 奖励写入失败：不得留下半事务。

## C. 46地图组
- [ ] 最后1件登记前不发整页奖励。
- [ ] 最后1件登记成功后恰好发1次整页奖励。
- [ ] 再开面板/再登录不重复发。
- [ ] 页面奖励数值与33A/V2.1一致。
- [ ] 页面完成不成为传送或跨大陆硬条件。

## D. 10大陆全收集
- [ ] C1完成38件后暴击几率+1个百分点，仅一次。
- [ ] C2完成61件后+1。
- [ ] C3/C4/C5各+2。
- [ ] C6/C7/C8各+3。
- [ ] C9/C10各+5。
- [ ] 十大陆全部完成累计+27个百分点。
- [ ] 大陆奖励不再消耗装备。
- [ ] 不得写成暴击伤害、致命几率或致命伤害。

## E. 旧角色补发
- [ ] 619状态不重发单件奖励。
- [ ] 已完成地图组但缺完成标记：仅补整页一次。
- [ ] 已完成大陆但缺大陆标记：仅补暴击几率一次。
- [ ] 已有完成标记：补发流程为0收益。
- [ ] 重复登录/打开命令保持幂等。

## F. 回滚
- [ ] 安装前有平台备份/事务收据。
- [ ] 回滚只针对本轮大陆完成桥和对应配置，不删除玩家原619收集状态。
- [ ] 已发永久属性若需回滚，按收据精确反向处理，不得全服统一清零。
