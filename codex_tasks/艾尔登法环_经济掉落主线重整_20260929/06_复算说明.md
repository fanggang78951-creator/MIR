## 运行

Python 3标准库，无外部安装：

```text
python tools/drop_contract.py --source-zip <R1完整ZIP路径> --out <新的空目录>
```

测试（Linux/macOS）：
```text
PYTHONPATH=tools python -m unittest discover -s tools/tests -v
```
PowerShell：
```text
$env:PYTHONPATH="tools"
python -m unittest discover -s tools/tests -v
```

输出目录必须为空，拒绝覆盖。输出drop_structure_candidate.json明确为STRUCTURE_ONLY_NOT_DEPLOYABLE；只将材料quantity改为1，不改分母、NPC成本和回收价。

## 边界

未完成定价、供给与真实路径，不能把输出直接变成MonItems上线。
函数expected_objects仅采用归档倍率模型、单正常结算轮，没有宣称真实服务器性能或所有额外机制。15个单元测试证明所声明的合同，不证明整个经济。
发现335条R1神器分母与历史角色统一值不一致，工具只列出并冻结输入，不替用户静默选择另一版本。
