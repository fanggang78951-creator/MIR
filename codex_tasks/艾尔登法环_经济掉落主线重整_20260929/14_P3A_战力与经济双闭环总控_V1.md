# P3A｜战力与经济双闭环总控 V1

日期：2026-09-30。主线：MAINLINE-20260929-R2。
状态：**双闭环目标口径已锁定；本文件是数值规划基准，不是部署证明。**

## 1. 两条闭环分开验收

### 战力闭环
上一大陆实际离开状态 → 本大陆持续打宝/换装/称号/收集/永久成长 → 本大陆正常内容约70% → 守关 → 下一大陆继承。

70%不是空降七成本大陆装备，也不是最终面板乘0.7。没有取得替代品的槽位继续穿旧装备；上一大陆实际保留的称号、图鉴永久奖励、神印、转生等继续存在。守关自身掉落不计入首次守关前70%分母。

当前R1累计人物与守关结果继续作为闭环锚点：C2—C10约70%参考的守关成功击杀中位约595—602秒，高完成度更快；C1继续使用低攻击、守关HP仅翻倍的例外。旧里程碑人物只能作连续累计锚点，不能把后期人物能力倒灌到入场刷取。

### 经济闭环
恢复用户早期已确认的交易纲领：**单个主号同阶段自身体系产出约30%—40%，市场/多号补足60%—70%。**
本版以 **35%自产 / 65%市场与多号缺口** 为计算中心。

因此正常主号若完全隔绝市场，只靠一个号刷，经济和材料有意跟不上装备/战力提升。这个缺口不是需要继续提高掉率的故障，而是交易与多号供养的设计基础。满赞助主号/正常市场参与用于战力主平衡；免费打金号保留供给和上升通道。

旧P2B/P2C/P2D“单号自己刷齐全部费用和材料”的路线降级为压力诊断，只用于发现极端等待、积压和异常，不再作为正常推进验收条件。

## 2. 货币闭环

当前基础经济统一按元宝口径试算；额外洗练/开光追求、充值货币、追梦神器、战灰不进入普通主线经济。

货币自产结构：
- 高价值大陆主材回收：约30%阶段元宝需求；
- 装备回收：约5%阶段元宝需求；
- 单号同期货币自产：中心约35%；

## 3. 材料闭环

基于当前578笔参考操作，并补回C2成长链费用，十大陆正常成长材料总需求为 **21,655件**。
按逐材料正整数取整后的阶段目标：
- 单号自产 **7,586件，约35.03%**；
- 市场/多号缺口 **14,069件，约64.97%**。

这里“材料件数”只用于供需覆盖率控制，不代表不同材料可以互换。需求只有1—2件的证物允许因整数导致单项比例偏离35%，但大陆阶段总量保持30%—40%。

## 4. C2经济漏项补回

旧资源模型将CAMP成长入口视为未定价，但战力人物已经使用宁姆格福成长装备。本版补回已确认的两条实际成长费用：

- 圣律真言LV1—LV10：1,440,000元宝 + 2,750失色锻造石；
- 黄金之心LV1—LV10：1,440,000元宝 + 2,750失色锻造石；
- 合计：**2,880,000元宝 + 5,500失色锻造石**。

因此参考元宝需求从63,549,930修正为 **66,429,930**。
C1圣律之剑/黄金圣物继续沿用既有灵符路径，不强行折算为元宝。

## 5. 经济与战力如何连接

战力约70%角色代表“上一大陆累计成果 + 本大陆约70%正常成长”。它不是完全隔绝交易的单号。
经济闭环有意只让主号自产约35%，所以形成战力70%参考所需的经济与材料中，约65%应通过市场、其他玩家或多号供养获得。

这正是用户要求的效果：**装备本身能持续更新，但单号经济/材料追不上完整成长，形成超过一半的长期交易缺口。**

不通过提高材料掉落、批量同名掉落或大量装备回收把缺口抹平。

## 6. 后续施工边界

本版先锁“需求和供给目标”，尚未把7,586件材料目标和各大陆主材目标全部反算成最终1/N。
下一步只做参数落地：
1. 以连续成长的实际阶段窗口计算普通/稀有/BOSS可击杀量；
2. 按独立材料、一轮同种最多1件、鞭尸额外轮分别反算基础分母；
3. 同阶制式继续RANDOM互斥；
4. 用入场→混装成长→70%→守关连续重跑一次；
5. 若某项自产超过40%或低于30%，只修对应来源，不重开整个体系。

脚本/引擎按用户最新要求视为正确执行，不再把平台bug、容量、并发或编译器核验当作数值闭环前置。
追梦实际R1/P1概率、战灰既定规则、一二大陆旧装备、C1例外均保持。
