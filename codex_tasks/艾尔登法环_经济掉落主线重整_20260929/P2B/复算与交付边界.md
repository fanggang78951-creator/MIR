```text
python tools/rebuild_p2b.py --source-p2a inputs/P2A_source.zip --work fresh_rebuild

```

```text
python tools/rebuild_p2b.py --source-p2a inputs/P2A_source.zip --work fresh_random --random --trials 16
```
