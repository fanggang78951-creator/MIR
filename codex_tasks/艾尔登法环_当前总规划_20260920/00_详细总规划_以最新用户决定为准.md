## 3. 地图处决与韧性：最后确认的双向软难度

### 3.1 系统目的

处决是增加目标承受伤害的状态机制，不是这里另造一个必死斩杀门槛。装备处决可以随进度显著增长，地图同步抵消基线，控制有效收益。**装备成长是主设计，地图削弱是平衡器。** 不允许先任意把地图压制堆高，再把早期装备硬凑成上百点。[U09—U15/S01]

地图规则固定于地图与阶段，不随某个玩家换好装备动态抬高，不能把强装备的优势全部抵消。低配可以进入、可以战斗，只是输出与生存更困难。

### 3.2 字段、单位与公式

最新上传13号为7列，名称、顺序保持：
`map_id, enabled, required_toughness, base_chance_bp, monster_execution_toughness, 中文说明, 填写说明`。[S12]

| 字段 | 正确作用 |
|---|---|
| map_id | 实际逻辑地图ID；每张物理图一条 |
| enabled | 1启用、0关闭 |
| required_toughness | 玩家达到该韧性时，不再受本地图怪物处决缺口风险 |
| base_chance_bp | 缺口最大时的基础概率；100BP=1% |
| monster_execution_toughness | 地图抵消玩家处决的参数；每点抵消0.1个百分点 |
| 中文说明/填写说明 | 人读说明，不会自动变成脚本逻辑 |

设玩家韧性R、地图要求T、基础概率B（BP）：
`怪物对玩家概率BP = B × max(0, T−R) / T`，启用时T必须大于0；达标归零。沿现有实现处理整数BP，不在本轮另定舍入方式。[S03/S12]

设玩家总处决E（百分点）、地图抵消参数S：
`抵消后处决百分点 = max(0, E−S/10)`。
实际触发概率最后受概率上限约束；不能先把装备总处决截为100%，再减地图，否则后期总量超过100%的设计被破坏。[U09及后续公式说明/S12]

2026-09-21用户进一步固定地图换算：**地图要求韧性必须是10的倍数；每10点韧性对应抵消1个百分点玩家处决。** 按13号表既有字段单位`monster_execution_toughness / 10 = 实际抵消百分点`，因此当前地图表中`monster_execution_toughness`与`required_toughness`采用同一数值；例如150韧性=抵消15个百分点处决。此条覆盖此前“两个字段可独立校准、不要求T=S”的旧解释。怪物对玩家的韧性缺口概率公式仍按required_toughness计算。[U22]

正常完成度约5—10是设计目标，不是`max(5%,...)`硬保底。未达标可以被抵成0；BOSS/合成/洗练/神器留出真实领先空间。不能仅凭有抵消就保证击杀时间绝对不变，持续时间、增伤覆盖、回刷低图等仍可能变化；本轮不为此修改其它属性。
