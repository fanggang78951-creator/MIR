## 单号自产模型
满充值/半急速角色，不向其他玩家购买装备和材料；C0–C2明确可用灵符的操作沿用，未明示的价格不视为免费。
采用上一批实际人物倍率与怪物TTK；输入已包含技能总体×2，不重复乘群攻。吸血×1.3不用于掉率。
“普通12只/600秒、稀有2只/600秒、地图BOSS1只/1800秒”是本轮每个怪物种类的可用供给假设，不是现服Mongen读取事实。
时间分配按普通72%、稀有18%、地图BOSS10%；可用击杀量同时受TTK和刷新供给限制。没有把所有地图同时产生的总量冒充单人每小时产量。
守关不计首次通关前常规收益；每日额外福利、市场交易、任务外赠品不叠到基准产出。
同物品的穿戴件、图鉴消耗件、合成基础件和备用件独立计数，留用后才拆解。主材先留够当期材料需求，余量才按1.5倍货币回收。

## 主要投放决定
1. 普通专属承担持续推进；稀有/BOSS本体装备是加速和追求。一个BOSS多件自有物品分别分配预算，不复制原概率使产量倍增。
2. 742处材料叠加数进行了需求驱动调整。提高触发后的单堆数量，避免大量高频散件；最大叠加数40。叠加语法与物品可堆叠设置必须在现服预检。
3. 制式只是辅助收入，已按每地图组与COM收入比较限制其触发频率；没有提高制式回收价格。
4. 六神器C2–C10同分类使用统一基础分母：普通20000000、稀有5000000、地图BOSS200000、守关40000。触发后六件等权选一，不是六次独立概率。
5. 25种称号卷为独立判定，基准角色有效率约：稀有2.5%、地图BOSS6%、守关8%，分母取整后存在合理偏差；不计其回收为主线资金来源。
6. 大陆收藏材料、追梦和特殊低频物品不列入基准通关资金。仓库缺口不能用假定卖出追梦来填平。
7. 怪物分母已经是基础值，导入后只由引擎正常应用一次人物爆率；不要把表中的有效概率反写后再次乘爆率。
8. 效率70%/130%、爆率80%/120%、可用刷新50%、C10回刷均单列，不承诺共享服务器竞争下仍有同一收益。
9. 不能仅凭通用基础分母就断言低级回刷完全无优势；实际仍受怪物供给、击杀时间影响，表内提供C10回刷对照，不新增限制玩家回刷规则。

## 文件效力
- 三张XLSX和561份标准JSON是当前数值定稿。
- 两套MonItems文字是便于Codex接入的适配文件；单行“1/N 名称”和“#CHILD 1/N RANDOM”使用项目既有形式。
- 叠加行暂按“1/N 名称 数量”表达，尚未取得本机解析器对第三参数的验证。必须先验证或按现有平台导出格式转换，不得直接假定可用。
- UTF8与GB18030是同一内容的两种编码，只安装一种；不是两份同时加载。
- 未完成的是部署预检和进服校准，不是再次要求用户选择装备数值或玩法。
