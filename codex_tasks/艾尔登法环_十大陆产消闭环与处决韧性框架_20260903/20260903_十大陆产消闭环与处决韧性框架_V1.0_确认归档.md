# 十大陆产消闭环与处决韧性框架 V1.0｜确认归档

日期：2026-09-03

## 一、本轮完成范围

本轮不填写真实怪物掉率、小时产量、回收金额、配方件数、装备属性或怪物属性，只完成关系层闭环：

`来源 → 资源 → 交易／转换 → 消费系统 → 回收边界`

现行成品为`十大陆产出消耗闭环总账_V1.0.xlsx`，包含：

- 263项标准化资源。
- 152条产出边，其中112条基础产出、40条每日额外守关福利产出。
- 486条消耗边，其中459条配方输入、7条既有系统建议消费、10条装备图鉴、10条大陆材料图鉴。
- 74项NPC／系统配方。
- 10个大陆经济闭环。
- A／B／C／D处决、韧性与围攻难度框架。

## 二、最新硬规则

1. 大陆毕业、地图达标和全服通关不设硬性时长；允许实际速度明显加快或变慢，甚至流派间出现数倍差异。
2. 人物达到地图正常阶段要求时必须能承受普通怪围攻；精英／BOSS同时出现按1—3只验收。
3. `有效韧性=人物总韧性-地图韧性要求`。有效韧性小于0时才可进入怪物处决判定；大于等于0时不因负韧性规则被处决。
4. 完成某地图／大陆全部专属装备收集给予较大的永久韧性，作为下一大陆A／B段安全挂机的主要软门槛。
5. A／B段无或极少处决，可安全挂机；C段需玩家关注，连续处决叠加围攻和1—3只精英／BOSS时允许死亡；D段全程危险。
6. 处决机制承担主要难度放大，怪物基础攻击只做合理递增，不通过怪攻与处决同时失控制造难度。
7. 23件重点合成装备、10件大陆生肖、5级群攻生肖共38项合成穿戴物可按原规则交易，但禁止普通回收。
8. 每日额外守关BOSS属于福利，40条福利产出边全部`计入基础模型=否`；主线世界守关BOSS仍计入正常Q04、专属和材料来源。
9. 核心稀缺瓶颈按自产30%—40%、玩家交易补足60%—70%设计；十件高产铸币主材不机械套该比例，必须先满足配方后仍有溢出用于金币／元宝回收。
10. 专属装备图鉴和大陆材料图鉴登记均消耗实物1件，不收金币、元宝或灵符。
