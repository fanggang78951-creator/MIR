## 二、本轮实际决定

1. C1/C2及前期制作共265件装备逐格保持原样；100命格数值、名称、ID和颜色不变。全817件物品名称、部位、资源来源编号不变。
2. 调整C3—C10普通专属227件，并联动9件稀有、51件地图BOSS、8件守关BOSS、25件合成成品，共320件、2773个字段。只调整常规战斗字段；没有给普通装备撒处决、突破、神力或吸收上限。
3. C3首图“拾骨弯刀”保留原标尺，保护已经完成的C1—C2—C3武器衔接。主要通过常规乘区和必要基础值让普通掉落有用，不按大陆把所有字段一齐翻倍。
4. 普通路线和强装路线分开。只取得当前组3/5或4/6种普通专属的专项人物，不夹带新图鉴、称号或洗练收益；38个后续组的这类换装输出提升约9.5%—23.3%。这是粗略范围，不是每条主线必须精确增加20%。
5. 已有BOSS或必做合成装备时，允许继续保留并提前推进。不能用普通支线的检验，强迫强装玩家每图换装；也不把强装玩家能越图作为设计失败。
6. 33件属性型合成的同槽边际输出贡献约2.24—2.40倍，基础攻击比较约1.5倍；不是人物总输出翻2—3倍。5级群攻生肖不再追加一套重复伤害属性。
7. 561怪按实际参考人物重新定HP和攻击等数值，采用技能整体2倍、吸血最多1.3倍。第一大陆只压攻击压力，不对HP使用低难度缩放。
8. 守关以约70%—75%本大陆准备度粗算；10个守关参考预算可过，同配装仅缺25点韧性时均形成明显生存风险。这里是模型预算，不是实服胜率试验。过关唯一硬条件仍是击杀守关。
9. 同图住民共用一套地图韧性和处决要求，没有为地图BOSS、守关BOSS暗设两套地图变量。
10. 地图BOSS92、守关BOSS10严格分开。保留此前22条配方26处依赖修正，不恢复守关材料作为首杀前必做合成唯一来源。配方、任务成本沿用最新大数值实际单价，不机械再乘100。
11. 20套制式来源全部覆盖；图鉴619件及46组/10大陆完成数量已同步；来源候选与爆率分开。5400条不是5400次独立掉落。

## 三、仍留给爆率阶段的内容

各掉落判定的具体1/x、产出/小时、自产所需时间、材料与币种实际供给速度。概率空白不代表0%、100%或已关闭。物品内容、数量、回收、成本以本批作为下一阶段输入；不重复恢复旧测试价。

不承诺全部玩家恰好在某小时毕业；不恢复21765灵符对应12小时、480/528小时、向玩家收购补足60%—70%等已废止规则。

## 四、设计定稿不等于部署成功

技术对接执行以下确定的预检，而不是继续让用户选择玩法：
- 物品按真实唯一Idx/名称更新，来源编号仅用于外观，不得以同外观合并两个物品。
- 怪物Appr、HIT、SPEED空白一律表示保留现服，不写0。攻击间隔的毫秒值单独映射，不把毫秒直接当成SPEED字段。
- C1的11层沿用已有层名定位；真实地图号从本地当前地图配置解析，不猜号、不新建地图。本批171个地图键中其余已有正式号按表使用。
- 后期HP最大约4.1×10^14，均能以64位整数和Excel数值精确保存；导入前检查实际引擎、数据库列、平台解析器的范围。禁止截断、回绕或私自把HP压到32位上限。容量不支持时只中止对应高值写入，保留本批设计，不假报导入成功。
- 命格攻速突破复用既有实际绑定；不创造假的内部ID。重复命格必须在装备/生效前被拒绝，历史槽结果不可额外叠加。
- 6件追梦神器和用户另行修改的称号卷保留本机现行数据，不在标准战斗人物中使用，不用旧文件覆盖。
- 现有付费入口、价格和脚本条件属于明确继承项；接口表中的0不能解释成免费。C2长期系统不要求在C2全部升满。
