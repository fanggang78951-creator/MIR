# 空白服装备共享文件引导设计

## 目标

精简翎风服务端缺少 `ItemDescList.txt`、`ItemRuleList.txt` 或 `GroupItemList.txt` 时，装备预检不再抛出 FileNotFoundError。平台把缺失文件列为计划中的 `create`，只在事务临时副本创建空文件，确认生成后才原子写入目标服；回滚恢复为原本不存在。

## 安全边界

- 只允许引导三个数据列表文件。
- `QFunction-0.txt` 是主脚本框架，必须保留目标服内容并按已验证的战斗成果包接入；不得创建空 QFunction。
- `ApexM2.DB`、`M2Server.exe` 和 `Mir200\Envir` 仍是目标识别必需项。
- 预检对目标服零写入；所有兼容核心检查都在临时镜像中执行。
- 已存在的共享文件逐字节复制到临时镜像，不覆盖、不清空。

## 验证

- 三个文件都缺失时预检通过并显示安全创建警告。
- 正式安装后文件存在且格式由原装备算法维护。
- 回滚后三个文件重新变为不存在，目标树逐字节等于安装前。
- 缺失 QFunction 或必要 anchor 仍阻止安装。
