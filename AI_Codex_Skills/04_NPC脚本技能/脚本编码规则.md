# 脚本编码规则

## XY-A-003 当前项目经验

记录时间：2026-06-16 10:29:28

1. 聆风/Mir类NPC脚本应优先使用 ANSI/GBK 编码。
2. 如果 Codex 用 UTF-8 保存 NPC 脚本，游戏内中文可能显示为乱码或“??”。
3. 如果游戏内 NPC 对话显示“??”，应先检查脚本编码和脚本文本是否已被问号替代。
4. 如果中文内容仍存在，只需转换为 ANSI/GBK。
5. 如果中文已变成“??”，需要重写中文文本并保存为 ANSI/GBK。
6. QManage、QFunction、Market_Def 下脚本、QuestDiary 脚本如包含中文路径或中文文本，也应注意编码。
7. 修改编码前必须备份。
8. 编码修复不得改变业务逻辑。

验证状态：
当前项目中 NPC2 已按 ANSI/GBK 重新保存；游戏内显示仍需用户重启 M2 后验证。

# XY-A-004 编码再修复经验

记录时间：2026-06-16 10:55:02

如果游戏内NPC中文仍显示“??”，不能只相信“已保存ANSI”的静态说法。

必须进一步检查：

1. MerChant是否指向正确脚本。
2. 脚本文本是否已经真实变成问号。
3. 文件是否真的按GBK/CP936保存。
4. 是否使用明确GBK写入方式，如 Python encoding='gbk' 或 .NET Encoding.GetEncoding(936)。
5. 如果脚本涉及中文路径，优先改成英文路径降低风险。

本项目已将变量保存目录从：
..\QuestDiary\玄渊系统\XuanYuanHumanVar.txt

调整为：
